# Personal Portfolio Website

A fast, responsive, single-page personal portfolio website built with **React**, **Vite**, and **React-Bootstrap**. Designed with a modular, component-based architecture for clean code maintainability, and powered by React’s `useContext` hook for global theme switching (Light / Dark mode).

## Features

- ** Lightning-Fast Performance:** Built with Vite for rapid bundling and fast reload speeds.
- ** Dynamic Theme Switching:** Global light/dark mode persistence powered by React's `useContext` API.
- ** Modular Architecture:** Clean component structure (Header->Navbar, About, Projects, Skills, Contact, Footer) for easy debugging and scaling.
- ** Responsive Design:** Fully adapted for mobile, tablet, and desktop screens using React-Bootstrap grid and utility classes.

- **Frontend Framework:** React.js

- **UI Framework:** React-Bootstrap / Bootstrap 5
